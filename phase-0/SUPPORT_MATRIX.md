The reference fixture demonstrates core composition only; it is not a production host or evidence for another provider. Splose stays unverified until account access and probes are available; its API documentation alone cannot establish account behavior. Product approval must assign each profile and capability a final `execute`, `requestOnly`, or `unavailable` mode with the cited evidence and a safe fallback. For standalone Cliniko, `requestOnly` also requires a proven Cliniko-owned durable request and staff route; without one, use `unavailable` and the approved caller fallback. A known unsupported or unsafe mutation never inherits execute mode from another provider.
