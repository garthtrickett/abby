# Synthetic media ingress and turn endpointing

`MediaTurnController` accepts ordered, session-scoped mono PCM16LE frames at 16 kHz. A transport adapter must authenticate the provider call, decode its codec, and resample before creating these frames. Each frame contains 10–100 ms of audio, a sequence number starting at zero, and a captured timestamp. The controller checks size, order, and time, copies the bytes before asynchronous work, and bounds queued frames. Raw audio and partial hypotheses never enter the ledger.

Abby detects speech onset from the average absolute PCM amplitude and waits for configured consecutive voiced audio before calling the voice session's `speechStarted`. It sends buffered onset frames to the transcription port with the resulting generation. The port returns partial or segment-final hypotheses in frame order. Configured trailing silence triggers a bounded `flush`; only then does Abby call `finishTurn` to mint a final caller turn. A long turn stops before it can become an action. Transcription calls have deadlines and abort signals, and stopping the controller cancels the active generation. Thresholds are configuration, not provider decisions.

The same frame path drives `SharedNumberVoiceCall` across its pre-location and location-scoped sessions. The two turn assemblers use different ID namespaces, so an identical provider utterance ID cannot make the location choice and first scoped action share a turn ID. Memory and PostgreSQL journeys use synthetic frames for location choice, booking details, and affirmation through one session; the host write occurs only in the chosen location. Focused tests cover ordering, copying, backpressure, timeout, cancellation, and overlong speech.

This is a provider-neutral synthetic proof. It has no live telephony authentication, provider codec implementation, real transcription or synthesis provider, or transport playback evidence. Before clinic traffic, provider-specific contracts must prove frame normalization, bounded latency, playback completion and clear semantics, transfer, disconnect, and fallback on a real media connection.
