# Local Cliniko voice service runner

`npm run voice:local` starts the standalone composition on `127.0.0.1:ABBY_VOICE_PORT`. It validates the route and provider configuration, verifies the PostgreSQL privacy boundary and active-call lock database, then exposes signed Twilio webhook and media paths. `GET /healthz` returns 200 only while PostgreSQL answers a probe; it is an operational liveness check. `GET /readyz` returns 503 while patient calls are disabled. Deployment routing must use readiness, not liveness, to decide whether to send calls. `SIGINT` and `SIGTERM` close active sockets and the database connection.

The runner needs a migrated `DATABASE_URL` and these environment values: `ABBY_VOICE_PORT`, `ABBY_TENANT_ID`, `ABBY_CLINIC_ID`, `ABBY_LOCATION_ID`, `ABBY_VOICE_ROUTE_VERSION`, `ABBY_CLINIKO_API_KEY`, `ABBY_CLINIKO_CONTACT_EMAIL`, `ABBY_CLINIKO_BUSINESS_ID`, `ABBY_CLINIKO_PRACTITIONER_ID`, `ABBY_CLINIKO_APPOINTMENT_TYPE_ID`, `ABBY_CLINIKO_TIME_ZONE`, `ABBY_TWILIO_TEST_NUMBER`, `ABBY_TWILIO_FALLBACK_NUMBER`, `ABBY_TWILIO_ACCOUNT_SID`, `ABBY_TWILIO_AUTH_TOKEN`, `ABBY_TWILIO_PUBLIC_WEBHOOK_URL`, `ABBY_TWILIO_PUBLIC_STREAM_URL`, `ABBY_TWILIO_BINDING_KEY_HEX`, `ABBY_GREETING_VERSION`, `ABBY_GREETING_APPROVAL_OWNER_REF`, `ABBY_GREETING_APPROVED_TEXT`, `ABBY_OPENAI_API_KEY`, and `ABBY_OPENAI_INTENT_MODEL`. The binding key is at least 32 random bytes encoded as even-length hex and must be identical on every serving instance. `ABBY_CLINIKO_BUDGET_USER_REF` is optional when a shared Cliniko user budget has been established. The public URLs must exactly match the eventual provider configuration. Never put secrets in the repository.

By default this runner supplies `unprovenReadiness` and returns 503 to a valid signed webhook before stream TwiML. `ABBY_VOICE_TEST_MODE=1` adds a restricted rehearsal path requiring an exact `ABBY_TWILIO_TEST_CALLER_NUMBER` and dialed test number on both the signed webhook and bound stream, plus healthy PostgreSQL and an explicitly enabled isolated automation setting. `/readyz` remains 503 for general routing. Caller ID is not proof of identity; use only a dedicated test number and synthetic/demo data. The greeting environment values represent a clinic approval only after a clinic owner actually approves the wording; setting them does not complete the clinic readiness gate. The Twilio trial has not proven its post-stream dial or number-level failure route on a real call. D-09 and D-12 therefore keep patient traffic disabled. `E2E-171` proves default refusal. `E2E-172` starts the runner in a separate process with isolated PostgreSQL and synthetic provider ports, and tests signed allowlisted admission, keypad output, interruption, forged stream rejection, and shutdown. `npm run voice:probe-runner-public` repeats the call path against that runner over a temporary public ngrok HTTPS/WSS tunnel using synthetic traffic. Neither is a carrier test. See the [real-call rehearsal runbook](VOICE_TEST_RUNBOOK.md).
