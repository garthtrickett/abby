# Synthetic voice session contract, version 0.1

**Status:** Executable no-number Phase 1 slice. The playback and transcript ports in this slice are synthetic. It is not a live media integration or a complete implementation of the [technical design](../TECHNICAL_DESIGN.md).

`VoiceSession` attaches to an admitted call and holds one transient `TurnAssembler` per connected session. A provider segment marked final is only a segment. Abby's `finishTurn` closes the turn and mints a stable ID from call, session, turn namespace, generation, and segment IDs. Partial text never enters the call ledger. A resolver may return an opaque booking offer and verification reference, an affirmation candidate, or a handoff reason; the reference host and typed call runtime make the actual business decision. The resolver cannot create a write or mark speech played. Booking calls through the same `TextReception` path used by the text contract tests.

`dispatchPending` durably marks the committed presentation `started` before it calls the playback port. A queued response does not count as played. Only an exact playback ID with `played` evidence updates that presentation and permits a later clear affirmative final turn to make its action ready. An unknown playback ID, a late result after interruption, and an interruption that cannot prove the transport queue was cleared cannot confirm an action. Uncertain enqueue and disconnect leave the durable presentation `unproven`; a failed clear ends the call. An `unproven` or interrupted presentation never authorizes the host write.

The same synthetic journeys run against the in-memory and disposable PostgreSQL ledgers. They cover final-turn assembly, queued versus played evidence, booking enabled and disabled settings, interrupted and late playback results, disconnect, uncertain enqueue, failed clear, and the enqueue/interruption race. Run `npm test` and `npm run probe:postgres`. Each new feature or setting must add a journey that exercises its caller-visible result and effect boundary on both compositions.

The [synthetic media controller](MEDIA_TURN_CONTROLLER.md) accepts normalized PCM frames and closes turns after Abby-owned silence endpointing. The [streamed playback port](STREAMED_PLAYBACK_PORT.md) converts approved text to audio chunks, checks the output gate before each send, and validates exact completion evidence before durable settlement. The [connected call owner](CONNECTED_VOICE_CALL.md) composes these paths for one synthetic call. Optional OpenAI speech/transcription and Twilio media protocol adapters now have synthetic tests, including a signed local WebSocket through the actual call owner; live provider validation and actual caller playback proof remain open. The current strict English affirmation matcher is a synthetic fixture; locale and natural-language confirmation policy still need an approved design. The [speech fence](SPEECH_FENCE.md) rejects an older asynchronous turn after a newer speech onset. Live callers must not use this slice for booking, and no real voice E2E claim is made.
