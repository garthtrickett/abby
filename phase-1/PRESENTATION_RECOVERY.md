# Durable presentation wake-up and recovery, version 0.1

`PresentationDispatcher.wake` handles a call-specific commit notification. `recover` scans at most 100 admitted, active calls with a pending presentation and an unexpired session lease; it excludes text-only test calls. It uses a call-ID cursor so repeated scans advance past pending calls whose sessions are temporarily missing, and dispatches different calls in groups of four. The standalone PostgreSQL scan uses the database clock; the in-memory adapter uses its deterministic test clock.

The dispatcher resolves each pending ref to an attached `VoiceSession` and verifies the exact call, scope, and session ID before delivery. The voice session reads the current pending presentation and atomically marks it started in the ledger before touching playback or transfer ports. A racing wake-up or second scanner sees the committed state and cannot send the same presentation twice. A missing session leaves the intent pending for another scan. The independent lease-expiry monitor eventually supersedes that pending intent if no session returns. A started presentation is never selected by recovery.

Memory and disposable PostgreSQL journeys enter through final caller speech, omit the normal wake-up, recover the durable intent, complete synthetic playback of the exact details, affirm, and produce one host booking. Another journey recovers a transfer and records one connected result. Separate journeys cover missing sessions, concurrent wake and scan, an incorrect registry mapping, and a registry exception. Run `npm test` and `npm run probe:postgres`.

The [in-process work loop](VOICE_WORK_LOOP.md) can schedule this recovery method, but the production host must still start it and wire relevant call-state commits to the notification hook. Neither slice proves a live media provider. The PostgreSQL JSON scan needs a measured index and operational cursor strategy before high-volume deployment. Session and transport loss still require the live provider route and number-level fallback tests.
