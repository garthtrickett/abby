# Model proposals from final voice turns

An opt-in voice intent now passes an Abby-final caller turn to the existing transient `ModelWork` and durable model effect. Partial transcription cannot reach the model. A low-quality final turn asks the caller to repeat without a model call. If the host chose model intent but supplied no model adapter, the same SAM call transition creates a staff fallback notice. The voice path passes its observed conversation revision to the model ingress, so a newer turn cannot make an older final turn current.

The effect worker decodes the model result through the typed proposal boundary. An answer creates a separate host-knowledge read; only an exact, current, approved match becomes pending speech. Action and lookup suggestions create staff work, not host writes. The voice session dispatches the committed notice and records playback evidence. Model inference itself never marks speech played or confirms an appointment. The deploying host must run the effect worker and delivery loop; a model adapter is not installed by default.

Synthetic voice journeys on memory and PostgreSQL ledgers cover approved answers, unclear speech, missing adapters, unsupported action proposals, caller correction, and `E2E-076` through `E2E-078` for malformed, unavailable, and timed-out model results. A separate journey rejects an older conversation revision before it queues model work. These use a fake model port and synthetic playback. No live LLM, speech provider, or telephony path is claimed. The next model work is a real provider adapter, a versioned evaluation corpus, and live latency and quality evidence.
