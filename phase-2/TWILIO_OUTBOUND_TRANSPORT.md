# Twilio + Abby outbound transport and original send context

This explicit guarded profile adds the first concrete Twilio carrier adapter at the existing runtime seam. It submits exactly one outbound API call after the current clinic owner fence. Abby remains responsible for workflow and clinical authority; a later Vapi adapter can own conversation transport behind the same selection, original-context and complete recovery contracts. No runtime fallback or retry is installed.

## Original context and cold callbacks

The native launch owner supplies a private fifth workflow argument only after an exact possible-attempt ACK and fresh preparation. The public transport payload remains exactly effectRef, capacityAllocationRef, number and profileRef. The canonical full original attempt is captured before dispatch, not reconstructed from editable Cliniko notes during recovery. The optional handoff preserves existing conditional fake/legacy adapters; this concrete adapter requires the guarded v4 contact/DNC context.

AES-256-GCM encrypts/authenticates the original native selection and complete possible note together with account, caller/recipient, exact provider/settings and a stable future report action. Independent key copies and purpose separation prevent config mutation or using a stream token as launch context. The selected binding covers account/auth fingerprint, caller, profile, public URLs, context-key fingerprint and transport deadline. Key rotation or another selected runtime cannot silently adopt the old context. Encrypted correlation is supplied to the provider; no private local mapping, native context digest, callback URL, secret or report is journalled in SQL.

The transport uses one HTTPS POST to the fixed Twilio Call resource, form encoding, explicit POST answer/status methods and the documented initiated/ringing/answered/completed progress events. It neither redirects nor retries. A bounded owned response reader accepts only exact parsed201 account/caller/recipient/outbound-api/root-call/URI truth. A known exact creation ACK survives later observer failure; absent/lost/foreign/malformed/oversized/aborted responses retain unknown. Call creation is not delivery, patient verification or completion.

Inbound HTTP callbacks require the configured exact public URL including the encrypted query, every signed form field, the installed Twilio validator, exact account/From/To/outbound-api direction and root call. Duplicate fields and altered targets refuse; extra provider fields are signed and retained only for validation. Answer admission expires ten minutes after the original attempt. A delayed queued answer refuses instead of repeatedly minting fresh media credentials from an old signature. This is a bounded conditional profile, not a promise of carrier queue time or a release rule. Authenticated progress remains historical facts only.

The answer emits Connect/Stream followed by Hangup, never a second Dial. The WSS URL has no query. Encrypted stream context binds the exact CallSid and receipt time under a separate purpose; each parameter is380 characters or fewer (combined name/value under Twilio500), with bounded count and exact reassembly. Upgrade signature, protocol/version, stream/account/call identities and a180-second start window are checked before private context is returned. A callback or stream remains an authenticated OUTBOUND event, never a fabricated inbound caller or verified patient.
