# Cliniko catalogue selection contract

`ClinikoCatalogueReader` lists bounded business metadata and checks one business, practitioner, and appointment type. Its `candidate` result means the selected metadata currently appears eligible for online availability reads. It never grants booking, patient disclosure, or staff-request authority.

`ClinikoCatalogueSetup` supplies the host-facing confirmation seam. The host provides an authenticated `HostActor`, account-scoped number routing, a versioned location policy, and a compare-and-swap approval store. Only a clinic admin for the reader's exact tenant, clinic, and location can list or approve. Approval requires a single-location route with the expected account, dialed number, and route version; the selected policy version; an eligible Cliniko snapshot no more than 60 seconds old; and a current credential fingerprint. Route and policy are checked before and after the provider reads. Concurrent changes to the approval record fail by version conflict.

An approval stores only clinic configuration: scope, selected Cliniko IDs, route and policy versions, key fingerprint, approver's opaque reference, and timestamps. It fixes both patient action and patient-specific request modes to `unavailable`. `resolveForCall` rechecks the route, policy, provider eligibility, credential fingerprint, and approval version; a revocation during recheck wins. The host must perform that check at each call binding before using the selected catalogue. These reads are sequential, so they cannot guarantee that Cliniko will not change after the final check. Available times remain provisional.

`MemoryClinikoApprovalStore` is a reference adapter and loses approvals on restart. A production host needs an authenticated identity source and a durable compare-and-swap store, then must connect `resolveForCall` to the number route. The current standalone voice runner does not consume this approval and cannot claim this setup flow is active. A demo-account read of the new catalogue is also still required. A real clinic must then confirm its own selection and wording; synthetic test actors do not supply that approval.
